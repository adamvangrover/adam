Governance Rules

  • No unreviewed code merges to `main`.
  • All agents must log decisions to `audit_trails`.
  • HFT algorithms strictly limited to $1M daily volume in simulation.
  • Model weights must be versioned with SHA-256 hashes.

W3C PROV-O & PDIL Gatekeeper

Provenance Enforcement

All probabilistic layer outputs must retain a reference to their source_data_object to enforce W3C PROV-O compliance. Validated via check_grounding on Pydantic schemas.

PDIL Gatekeeper Middleware

LLM inferences must be validated by the JsonLogicGovernanceGatekeeper. Inferences must contain a provenance_trace key satisfying the ProvenanceHeader schema; otherwise, a GovernanceError is raised.

MRM Standards (SR 11-7)

All generative models and deterministic pipelines must adhere to Federal Reserve SR 11-7 guidelines, requiring strict model validation, ongoing monitoring, and comprehensive whitepaper documentation.

EU AI Act Compliance

High-risk AI systems must maintain transparent audit logs, deterministic fail-safes (Rust Execution Layer), and human oversight loops as mandated by the EU AI Act.

Governance Simulator

Requires all agent outputs to contain a valid provenance_trace hash linked to the source_data_object.

Rejects any response payload that contains keys not explicitly defined in the Pydantic schema.

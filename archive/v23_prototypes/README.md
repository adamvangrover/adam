# Archive: v23 Prototypes (`v23_graph_engine`)

## Overview
This directory contains archived Proof-of-Concept (PoC) code and showcase assets from the v23 Graph Engine effort:
- `v23_graph_engine/cyclical_graph_poc.py`
- `v23_graph_engine/adaptive_system_poc.py`
- `v23_graph_engine/directory_manifest.jsonld`
- `v23_graph_engine/index.html`
- `index.html`

## Production Equivalents
These PoCs were superseded in production by:
- `core/engine/cyclical_reasoning_graph.py`
- `core/engine/states.py` (`PlanOnGraph`)

They are preserved in `archive/v23_prototypes/` for historical reference and teaching value.

Aggregator State Machine Synthesis & NLI Entailment

The aggregator state machine condenses multi-agent debate and qualitative data extraction into concise operational directives. To prevent the aggregator from introducing unsupported assertions during compression, the evaluation pipeline decomposes outputs into atomic propositions $\mathcal{P} = \{p_1, p_2, \dots, p_k\}$ and runs directional Natural Language Inference (NLI) against base state telemetry traces $\mathcal{T}_{\text{base}}$.

Decoupled Rubrics & Compute Proportionality

Generic quality prompts fail when judging deep research outputs. Supervisory judges evaluate multi-step trajectories across four independent mathematical axes. Compute efficiency is tracked dynamically to penalize compute inflation on trivial tasks or budget waste under adversarial stress.

Axis 1 Step Entailment

Premise Monotonicity

Verifies that intermediate deductions maintain logical consistency without mid-trace contradiction under adversarial persuasion.

$$\forall k, \, \text{NLI}\left(\bigwedge_{j=1}^{k-1} P_j, L_k\right) \neq \text{Contradiction}$$
Axis 2 CAD Index

Evidence Grounding

Measures ratio of verified source citations to factual claims. Eliminates pattern-completion source hallucinations.

$$\text{CAD} = \frac{N_{\text{verified\_citations}}}{N_{\text{factual\_assertions}}} \ge 0.85$$
Axis 3 Information Gaps

Epistemic Boundaries

Audits the model's ability to explicitly identify missing parameters rather than extrapolating unsupported figures.

$$\text{Abstention Precision / Recall on Undecidable Data}$$
Axis 4 Token Efficiency

Compute Proportionality

Tests dynamic test-time compute allocation against task difficulty. Detects token inflation and search loop stalls.

$$\text{Efficiency} = \frac{\Delta \text{Accuracy}}{\Delta N_{\text{tokens}}}$$

Formal Confidence Calibration & Adversarial Risk Loss

Uncalibrated models under adversarial stress frequently exhibit hallucinated certainty—claiming $\ge 95\%$ confidence on completely incorrect conclusions. To quantify miscalibration, predictions are partitioned into 10 equal-frequency quantile bins to compute Expected Calibration Error (ECE) and penalized using an asymmetric loss function $\mathcal{L}_{\text{risk}}$ ($\alpha \ge 5.0$).
